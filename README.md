# MountainShooter

Projeto de estudo em **Python + Pygame** criado para praticar estruturação de código, loop de jogo, telas, menus, recursos gráficos e organização de um projeto de game development.

> Este repositório representa uma etapa anterior de aprendizado e não é um dos projetos principais do meu portfólio atual.

## Tecnologias

- Python
- Pygame 2.6.1

## Executar

```bash
python -m venv .venv
```

No Windows:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## Estrutura

```text
MountainShooter/
├── asset/
├── code/
├── recursos/
├── main.py
└── requirements.txt
```
